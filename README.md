# Explorador

App móvil (React Native + Expo) para registrar lugares con foto, ubicación y brújula.

## Funcionalidades

- Cámara (nativa): tomar y guardar fotos en el diario
- Ubicación GPS (nativa): coordenadas, dirección y apertura en mapas
- Brújula (sensor magnetómetro)
- Adaptación Android/iOS con `Platform` (sombras, GPS, mapas, teclado)
- Navegación únicamente por Tabs (Expo Router)

## Ejecutar

npm install
npx expo start
